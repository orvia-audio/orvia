# Reading recognition model

Orvia uses the multilingual Whisper tiny model quantized to Q5_1 by whisper.cpp. The mixer runs inference locally when a reading is in progress.

- [Upstream weights and license](https://github.com/openai/whisper)
- [Distributed model at the pinned revision](https://huggingface.co/ggerganov/whisper.cpp/blob/5359861c739e955e79d9a303bcbc70fb988958b1/ggml-tiny-q5_1.bin)
