# Listening samples

[Download the A/B player](listen.html?raw=true) and open it in your browser. Play either recording and switch between the original and the filtered voice at the same point. DeepFilterNet3 is selected when you open the player.

| Filter | Keyboard typing | Air conditioner |
| --- | --- | --- |
| Off | [FLAC](keyboard-original.flac?raw=true) | [FLAC](air-conditioner-original.flac?raw=true) |
| DeepFilterNet3 | [FLAC](keyboard-deepfilternet3.flac?raw=true) | [FLAC](air-conditioner-deepfilternet3.flac?raw=true) |
| RNNoise | [FLAC](keyboard-rnnoise.flac?raw=true) | [FLAC](air-conditioner-rnnoise.flac?raw=true) |
| WebRTC | [FLAC](keyboard-webrtc.flac?raw=true) | [FLAC](air-conditioner-webrtc.flac?raw=true) |

Each clip contains the same 14 seconds at matched gain. RNNoise reduced the most noise before speech began in these two mixes. DeepFilterNet3 scored highest for speech intelligibility on both.
